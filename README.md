## About This Project

This portfolio was designed and developed as a personal space to present my professional and academic journey in a more interactive way.

It highlights my experience across software development, system automation, project collaboration, research, and technology-driven business solutions, while reflecting my interest in bridging technology, business needs, and users.

The website was built from the ground up using React and Vite, with custom styling, responsive layouts, motion effects, interactive project details, and original visual direction.

## Responsive Design

The interface is optimized across the following primary breakpoints:

- `900px` — Tablet / small desktop
- `768px` — Tablet portrait / large mobile
- `640px` — Mobile
- `420px` — Small mobile

Layouts, typography, spacing, interactive elements, and visual effects are adjusted across screen sizes to maintain usability and visual consistency.

## Getting Started

The following steps are only needed if you want to run the project locally on your own computer.

### 1. Clone the Repository

```bash
git clone YOUR_REPOSITORY_URL
```

Then enter the project directory:

```bash
cd YOUR_REPOSITORY_FOLDER
```

### 2. Install Dependencies

```bash
npm install
```

This installs the packages listed in `package.json`, including the libraries required by the project.

You normally only need to run this once after cloning the repository, or again when project dependencies change.

### 3. Start the Development Server

```bash
npm run dev
```

Vite will start the local development server and provide a local URL that can be opened in the browser.

### 4. Create a Production Build

```bash
npm run build
```

This creates an optimized production build of the portfolio.

### 5. Preview the Production Build

```bash
npm run preview
```

This can be used to preview the production build locally before deployment.
